发布到博客

文章经由 GitHub Issue 发布。按顺序完成下面几步，提交后一两分钟会出现在博客上。

  1. 复制正文

    文章较长，无法通过链接预填正文。先复制，再粘贴到 GitHub 的“文章正文”框。

  2. 打开 GitHub 表单

    标题、摘要、标签和正文已经预填，检查一下排版。

    打开 GitHub 表单 ↗

  3. 上传配图

    在“图片上传区”按顺序逐张粘贴，等每张都出现链接后再提交。同步时会自动放回正文原来的位置，图片说明也会保留。

    1. 勾选“同步到个人博客”，提交

      一两分钟后文章会出现在 博客。之后直接编辑这条 Issue 就能更新文章。

    仓库公开：Issue 与图片都可以被他人看到。草稿仍保留在本机，发布成功后可以清空。
