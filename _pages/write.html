写文章

在 GitHub 的文章表单里写作，直接粘贴截图或拖入图片。提交后，文章会自动同步到这个博客。

打开文章编辑器 ↗
  1. 填写标题和正文，图片可直接粘贴到正文框。
  2. 用 Preview 检查排版；需要目录时，用 Markdown 的 ## 和 ### 写小标题。
  3. 勾选“同步到个人博客”并提交。之后编辑这条 Issue，中文版文章也会更新。

仓库与 Issue 均公开，未勾选同步的内容也能在 GitHub 被看到。请勿在这里保存私密草稿。
