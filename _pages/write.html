② 在 GitHub 新建文件 ↗
  1. 先复制文章内容。
  2. 打开 GitHub，把上面的文件名填到顶部，粘贴文章内容。
  3. 点击 Commit changes，选择提交到 master。

勾选“公开发布”的文章，提交后会出现在 博客列表。本仓库是公开的；即使未勾选，提交后的文件也能在 GitHub 被看到。私密草稿请只保存在本机。
