直接在 GitHub 的文章表单里写。正文框支持粘贴截图、拖入图片、格式工具栏和预览；提交后会自动同步到这个博客。

打开文章编辑器 ↗
  1. 写标题、正文。图片直接粘贴到正文框，等待 GitHub 上传完成。
  2. 点击 Preview 看排版。准备公开时勾选“同步到个人博客”。
  3. 提交 Issue。博客文章会自动生成；之后编辑这条 Issue，文章也会同步更新。

这个仓库和 Issue 都是公开的，提交后即使没有勾选同步，内容也能在 GitHub 被看到。请勿在表单里保存私密草稿。
